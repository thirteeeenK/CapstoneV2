Application Layer — ChatbotService orchestrator
  1. Entrypoint & Session
    ChatbotController.chat() validates message ≤1000ch + user_lat/lng
    EnforceGuestChatLimits: 15 msg/day/IP + 5/min burst
    ConversationManager.resolveSession(): guest→login claim, isolation, latestForUser()
    history(): 6-turn window · summarizeHistory() if >20 msgs
    POST /chat session_token
  2. Abuse Guard
    GeminiService.detectAbuseAndGuard() — 42+ keywords (NSFW, prompt injection, Taglish)
    guest → 403 keyword block · authed → block + ChatbotAbuseReport + chatbot_flag_count → possible ban
    security
  3. Human Handoff Gate (state machine)
    If SupportInquiry is PENDING → pending_assignment · HUMAN_ACTIVE → control: admin
    Bypasses Gemini entirely · SupportQueueService atomic ticket claiming (polling)
    bypass LLM
  4. Conversational Memory
    isFollowUpQuery() · isFilterRefinementQuery() · isAffirmativeSearchQuery() · isWeatherAdvisoryFollowUp()
    resolveConversationalDestination() inherits last destination from last bot cards
  5. FAQ Shortcut
    FaqService.findBestMatch() · verbatim answer · 0 LLM cost · idempotent
    Skipped if bare amenity filter or explicit destination
    zero LLM
  6. Intent Router — 13 intents
    IntentRouter.classify(): ROOM · HOTEL · ACTIVITY · PACKAGE · ADDON · ITINERARY · AVAILABILITY · MAP · WEATHER · DISCOUNT · BOOKING_STATUS · DESTINATIONS_OVERVIEW · GENERAL_TALK
    extractConstraints(): pax, max_price, destination_id, hotel_id, room_id/addon_id, check_in/out, nights, limit, place_names
    resolveDefaultDestination() + blendedVector 0.65·user + 0.35·query (L2-norm) when isPersonalized()
    hybrid retrieval
  7. Intent Handler (match)
    ROOM → searchRoomsHybrid() + sortRoomsByPrice + pax hintHOTEL → searchHotels() + sortHotelsByPrice ACTIVITY → searchActivities()PACKAGE → searchPackages() <=> SQL ADDON → searchAddOns()ITINERARY → buildItineraryContext() AVAILABILITY → RoomAvailabilityServiceMAP → DistanceService (Haversine) WEATHER → WeatherService + DSS scoreDISCOUNT → passenger_category_rules BOOKING_STATUS → Booking→user_id scopedGENERAL → no retrieval
  8. Context Builder
    getRoomContext() / getHotelContext() / getActivityContext() / getPackageContext() / getAddOnContext()
    + extractPricingContext() — pre-computes pax × nights totals for prompt grounding
  9. Prompt Writing
    buildPrompt() + loadChatbotSystemPrompt() → SystemPrompts/chatbot-system-prompt.md
    + 6-turn history + userProfile (user_preferences) + cachedContents TTL 86400s
  10. AI Generation & Response Handling
    GeminiService.generateChatResponse() → gemini-2.5-flash-lite (temp 0.4, topP 0.95, max 1024)
    ConversationManager.persist(user+bot + context_data) → JSON { reply, retrieved_rooms/hotels/activities/packages, control: ai|admin|pending, session_token }
    AI Service Layer control flag
